# Rocket Animation

Rocket Animation built using HTML, CSS, and a touch of JavaScript. This small project shows a cute moon with a rocket orbiting around it using pure front-end code — perfect as a demo, learning resource, or an embeddable animation for a portfolio.

</p>

## Features

- Smooth orbit animation implemented with CSS keyframes.
- Playful moon illustration with craters, eyes, blush, and a shadow.
- Minimal, easy-to-read code (HTML + CSS) so you can learn and customize quickly.

## Built With

- HTML
- CSS
- (A tiny bit of JavaScript can be added for interactivity, but this demo is purely CSS-driven)

## Getting Started

To view the animation locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/BinaryVortex/Rocket-Animation.git
   ```

2. Open `index.html` in your browser (double-click or use your editor's Live Preview).

Alternatively, serve the folder with a simple static server (recommended if your browser blocks local resources):

```bash
# using Python 3
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

## File Structure

- `index.html` — markup for the moon and rocket animation
- `style.css` — all styles and animations
- `Screenshot 2024-08-27 172834.png` — preview image used in this README

## Customize

- Change colors in `style.css` to match your theme.
- Adjust the `@keyframes spin` duration to speed up or slow down the rocket orbit.
- Add JavaScript for additional interactivity (click to launch, toggle speed, etc.).
